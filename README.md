# HR_Attrition_Powerbi_Analysis_Dashboard
Created dynamic dashboard with slicers, KPI cards, Matrix visuals, Bar charts, Donut charts, and trend analysis for executive reporting
## Project Overview

This project analyzes employee attrition using Power BI.

## Tools Used

- Power BI
- Excel
- Power Query
- DAX

## Dashboard KPIs

- Total Employees
- Active Employees
- Attrition Rate
- Average Age
- Average Experience

## Insights

- Higher attrition in Administration and Sales
- Low salary employees have higher turnover
- Early-career employees are more likely to leave
- Job satisfaction strongly impacts attrition
